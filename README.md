# 云集智能视频预处理插件 (Yunjii Video Preprocessing)

ComfyUI 插件，用于视频预处理，自动提取关键帧、检测镜头切换和分析运镜。

## 功能特性

- 自动检测视频镜头切换
- 自动保存关键帧（区分有人物和无人物）
- 自动分析运镜方式（平移、俯仰、静态等）
- 一键上传视频

## 节点说明

### 视频预处理 (Video Preprocessor)

分类：`Yunjii/Video`

输入：
- 视频文件：选择 input/ 目录下的视频
- 检测灵敏度：镜头检测灵敏度（默认 0.5）
- 保存关键帧：是否保存关键帧（默认 True）
- 视频路径：可选，直接输入完整路径

输出：
- 运动提示词：用于视频生成的提示词
- 分段信息：详细的分析报告
- 镜头数：检测到的镜头数量
- 关键帧信息：JSON 格式的关键帧元数据

## 使用方法

1. 在 ComfyUI 中添加「视频预处理 🔍」节点
2. 点击「📂 上传视频」按钮上传视频
3. 确保「保存关键帧」为开启状态
4. 运行！
5. 关键帧会自动保存到 `output/keyframes_视频名/` 目录
